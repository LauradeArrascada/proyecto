Este es mi primer sitio web

Durante el desarrollo de Huellitas Pet Shop busqué crear una identidad visual cálida y cercana, pensada para personas que cuidan a sus mascotas. Organicé el sitio con una navegación clara, páginas separadas para productos, servicios, preguntas frecuentes y contacto, y un diseño adaptable para distintos tamaños de pantalla, con enfoque mobile first.

También resolví aspectos técnicos del proyecto, como la organización de los estilos con Sass, la compilación del CSS, la corrección de rutas entre páginas, imágenes y enlaces, y la validación de la estructura HTML. El historial de cambios del proyecto se encuentra registrado en Git y puede consultarse en los commits del repositorio.
Tuve inconvenientes con el ida y vuelta de páginas y con los enlaces.
